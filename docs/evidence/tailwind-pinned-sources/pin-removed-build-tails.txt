WHAT IT MEASURES. Under automatic detection the stylesheet moves when a file that is not markup moves:
A3 -> A2 is +18 bytes caused by nothing but the presence of a test file in the scanned tree. The pin
makes the served bytes a function of markup alone. That is the pin's justification, and it is the reason
`src/tailwindSources.test.js` is deliberately outside the pinned set (it is the list's own guard, not
markup) - which is also why the pin is what keeps this defect from coming back.

WHAT IT DOES NOT SAY. A2's 35823 B is not a defect in the merged tree: the merged tree carries the pin
(A1 = 35306 B). A2/A3 describe what WOULD happen if the pin were removed. And the +18 B is not a styling
change in any of the three states - see the leaf diff in this directory.
