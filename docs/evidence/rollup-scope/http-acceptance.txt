## 2. What each tab shows

   AE tab: panel copy reads "Every UAE case with the items still missing, named here …"; the
           roll-up lists the AE case only (7 outstanding); the "Cases open" tile above it agrees.
   KSA tab: panel copy reads "Every KSA case with the items still missing, named here …"; the
           roll-up lists the KSA case only (6 outstanding — the KSA document set, so the two tabs
           are not showing each other's cases); no AE row appears anywhere on the tab.

## 3. The empty state

   With no KSA case in the scratch database, the KSA tab reads:

     "No open KSA pre-boarding cases — nothing outstanding to show for this jurisdiction.
      Record an accepted offer to open one."

   The totals tiles are hidden rather than reading "0 ITEMS OUTSTANDING" as if it were a result,
   and nothing reports an error.
