## The two findings the setup itself produced

1. **`origin/main` was `404b29d`** — the merge of PR #79 (`feat/p2-3-pre-reading-package`),
   which had landed in the hours before this pass. The task's own description predicted the
   opposite ("the pre-reading package is not built yet (P2-3 in progress)"), so the script was
   written against the built package rather than around its absence — see the evidence README.
2. **The seed's own log states the three states it created**, dated as offsets from the run:
   DEMO-01 start seed+14 (on track), DEMO-02 start seed+1 (inside 48 hours), DEMO-03 start seed-1
   (start date passed, items open).
